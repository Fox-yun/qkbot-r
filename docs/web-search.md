# 联网搜索

首版提供 Tavily 搜索摘要，不抓取任意网页或执行网页指令。`/搜索 关键词`（或 `/search 关键词`）直接返回摘要和真实来源；模型通过 `web_search` 获取同一服务的结果并组织回答。

## 启用与调试

1. 管理页「联网搜索」填写 Tavily API 密钥，或在服务环境中设置 `QKBOT_SEARCH_API_KEY`。留空保持已保存密钥，清除按钮只清除文件值；环境变量仍优先。配置快照不返回密钥明文。
2. 点击「测试搜索连接」，使用固定的 `Rust programming language` 检查连接。测试只发一次可能计费的请求，不保存设置，不使用群聊数据；临时填写密钥只用于本次测试。
3. 启用联网搜索，保存并应用。直接发送 `/搜索 Rust 最新版本` 验证命令入口。各群和好友可在会话插件开关中单独关闭联网搜索。
4. 需要 AI 搜索时，在全局工具列表勾选 `web_search`，并开启模型原生工具调用；已有独立工具设置的会话也需允许该工具。不会自动修改已有会话权限。可发送 `@小鱼 联网查一下 Rust 最新版本，给出来源`。

完整参数参见 `config.example.toml` 的 `[plugins.web_search]`。默认每轮 1 次、每用户每小时 10 次、每物理会话每小时 30 次、全局每小时 60 次；用户额度在同一个机器人账号的群之间共享。默认并发 2、超时 8 秒、最多 5 条、响应上限 256 KiB、结果 JSON 上限 6 KiB。搜索超时必须短于工具总超时。管理页连接测试单独限制为一个在途请求，至少间隔 5 秒；命令和 AI 共用持久化小时额度。

固定使用 `https://api.tavily.com/search`、Bearer 认证、`search_depth=basic`，关闭自动参数、供应商生成答案、原始全文和图片。参数依据 [Tavily 官方搜索接口](https://docs.tavily.com/documentation/api-reference/endpoint/search)。`time_range` 可选 `any/day/week/month/year`；它表示供应商的发布时间或更新时间过滤，未知发布时间保持空值。

## 执行边界

- `Tool::apply` 仍仅做本地事务工作。外部工具用 `NetworkRead` 和 `ExternalTool`：短事务核验并预占额度，事务外异步请求，再用短事务核验并登记结果。网络等待不占用 SQLite 工作线程。
- 全局工具授权、插件 epoch、访问 revision、会话 epoch、会话插件 revision 和会话工具授权均复核。结果用于 AI 回复时，发送账本在提交前继续检查搜索授权；停用、重置或重新应用配置会丢弃过时结果。
- 请求发出前原子预占额度；失败也计次。同轮同参数复用有界结果；重复在途、超时、连接中断和重启均不自动重放。SQLite 不能与供应商计费形成原子事务。
- 查询必须为 1–300 字，拒绝未知字段、任意地址、Header 和身份参数；生产端点不可配置，禁止重定向。只发送查询和固定检索参数。模型被要求仅发送必要关键词，不发送聊天记录、长期记忆或身份信息。
- 搜索摘要只作为工具资料进入模型，不授予权限，也不成为长期记忆的原文证据。网页提示词无法绕过本地写入的用户确认。语义上的恶意内容仍需模型遵守宿主规则，程序不能保证每项推理都正确。
- 宿主分配本轮来源编号，普通文本和 `reply_message` 共用来源处理；未核实的模型 URL 和未知来源编号被标记，来源列表使用实际检索 URL。无结果或失败会明确注明未核实。此校验保证链接出处，不保证材料与每句话都相符。
- 日志仅记录操作 ID、耗时和状态，不记录密钥、查询或响应正文。为同轮幂等，数据库会短期保存有界查询结果，随工具账本保留策略清理。

## 本地验证

Windows 使用 `./scripts/cargo.ps1 test --offline` 和 `node --test tests/admin_frontend.mjs`。搜索单元测试覆盖真实回环 HTTP 协议、429/401、重定向、无结果、无效 JSON、分块超大响应、UTF-8 裁剪、并发、超时、取消、配额、幂等、失效授权和来源渲染。测试使用模拟密钥，不消耗 Tavily 额度。真实中文召回、部署网络和上游计费需在填写密钥后通过管理页和 QQ 入口核验。
